🎯 Number Guessing Game

The Number Guessing Game is a fun and interactive game where players try to guess a hidden number within a selected range. The game can be played in Single Player Mode against the CPU or in Multiplayer Mode, where players can create and join rooms to compete with friends.

Players can choose their preferred difficulty range, such as 1–100 or 1–1000, making the game suitable for both quick and challenging rounds. After every guess, the game provides hints like “Higher” or “Lower” to help players reach the correct answer.

With simple mechanics, multiplayer support, and customizable difficulty, the game offers an engaging experience that combines fun, strategy, and logical thinking.


🎮 How to Play
🚀 Start the game
🎯 Choose a mode (Single Player / Multiplayer)
🔢 Select the range (1–100 or 1–1000)
🏠 Create or join a room in multiplayer mode
🤔 Enter your guess
⬆️⬇️ Get hints like “Higher” or “Lower”
🔄 Keep guessing until you find the number
🏆 Win by guessing the correct number in the fewest tries!
